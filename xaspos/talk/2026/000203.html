It's been some time since we made open source some of the infrastructure...

Since 2025, a lot of our infra has been replaced, removed, and adquired. The public documentation and maintenance guides currently reflect our 2024 architecture. New team members, open source contributors, and even our own SRE team are struggling with missing context, outdated runbooks, security gaps, etc.

Phase 1: Discovery & Inventory
Phase 2: Documentation Updates (3 weeks)
Phase 3: Tooling & Automation (2 weeks)
Phase 4: Community Communication (1 week)

Acceptance Criteria
* All public documentation accurately reflects infrastructure as of 26Q1 (2026 Quarter 1)
* New team members can successfully deploy and maintain all components using updated docs
* Acquired services have clear maintenance and contribution guidelines
* Deprecated components are marked as archived with migration paths
* Documentation passes automated validation (links, examples, code blocks)
