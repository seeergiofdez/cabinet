Hi,
We've recently modified most of our VPN infrastructure, based on Mullvad, which reduces latency, adds tons of new locations and finally uses advanced configuration.

You can generate and import configuration files in WireGuard Configuration Generator.

1. Navigate to your BBJProjeK account, and under Platform, select Manual.
2. Click on Generate key. (You can generate a separate key pair for each device that you use.)
3. Select a county / city / server.
4. Optionally select the DNS content blockers that you want to use.
5. Click Download file to save the file. You may need to wait a few seconds for the file to begin downloading.
6. Open the WireGuard app.
7. Click Add Tunnel, select the downloaded file, then click Open.

To unblock the local network in the WireGuard app for Windows you can click on the Edit button and turn off Block untunneled traffic (kill-switch). However it is not recommended to keep it off permanently as it can open up for possible IP or DNS leaks.

Hope this new releases enhances your experience on the organization.
