Quick heads-up, a little spring cleaning in March

Just a quick note as we head into March. As part of our ongoing quest to keep things tidy and efficient, we’re going to be doing a bit of digital spring cleaning next week.

* Swiftlynx Service: We’ll be saying goodbye to the Swiftlynx service. It will be officially deprecated as of next week.
* Subdomain Cleanup: We’re also tidying up some old subdomains that are no longer in use. If you were using a specific legacy URL for anything, please double-check that you’ve migrated to the current standard endpoint.

This shouldn't cause any disruptions if you're on the latest versions, but feel free to ping me if you have any questions or run into any lingering links.

Cheers,
