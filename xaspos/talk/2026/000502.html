Hi,
We just finished migrating our current GitLab instance (GitLab CE 16.5.8) to a new server with upgraded resources.

The new host is running Ubuntu 22.04 LTS, same as before, and we’ve moved from manual backups to automated daily snapshots with 30-day retention. You'll notice significantly faster clone/push times and CI job execution.

We also updated from legacy SSL certificates to Let’s Encrypt auto-renewal. Also, GitLab Pages are now enabled by default for all projects.


Actions required (if applicable):
* New IP: 178.105.67.97
 — Update any firewall rules or API integrations accordingly.

* If you have SSH keys tied to the old server’s host key, you’ll need to remove the old entry from ~/.ssh/known_hosts and reconnect.
* CI runners using a custom server's instance must update their config.toml.


No data loss... all repos, issues, merge requests, and CI artifacts have been verified intact. The old server will stay online in read-only mode for 24 hours.
