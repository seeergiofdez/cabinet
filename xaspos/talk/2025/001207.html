It's been some weeks since my last update about working on KanXras performance. Uneventful for KanXras, but very eventful for me, as I've been hard at work adding new optimisations in the background to fix any bottlenecks that had creeped in! We now have:

- A faster blocklist matcher
- Improved caching logic
- Tuned database/cache connections
- More to come; still have some things I'd like to mark as done!
