We're happy to announce that we successfully deployed our own self-hosted GitLab environment, based on GitLab 16.4.7, a version that best work for everyone, with a good UI and better performance.

BBJProjeK GitLab is now available at: ax.bbjprojek.org.

Every BBJProjeK email address is suitable for using GitLab. Request access to your administrator.

Every account can create unlimited personal repositories which are linked to the profile. Each repository can be either public, or private. A public repository may appear in the main and explore page of BBJProjeK GitLab, it can be starred, forked but cannot be edited by others. You can invite collaborators for edition permissions.

GitLab SaaS will be deprecated on March, 2026.

Ragyxo and RaBBAu have been already migrated to our new GitLab infrastructure, and their old repos have been archived.

Need more info? Stay tuned at https://wiki.bbjprojek.org/docs/services/gitlab/ to learn more information that will be published soon.

Happy coding!
